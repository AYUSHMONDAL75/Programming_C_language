# Programming in C Language

This repository has all the C programs I wrote while learning C.
It has basic programs, string programs, matrix programs, linked lists and two small games.
No file handling is used in any program.

## How to run

Compile with gcc and then run the exe:

    gcc file_name.c -o file_name
    ./file_name

On Windows (PowerShell):

    gcc file_name.c -o file_name
    .\file_name.exe
